# Content Writing Skill — Prime Ceramics

## Brand Voice

### Tone
- **Confident, not boastful**: "Crafted to perfection" not "The best tiles ever made"
- **Warm, not cold**: "Surfaces that bring spaces to life" not "High-performance ceramic products"
- **Precise, not vague**: "Fired at 1200°C for 45 minutes" not "Made with advanced technology"
- **Inviting, not pushy**: "Discover your surface" not "Buy now! Limited offer!"

### Writing Rules
- Short sentences. Direct language. No fluff.
- Use sensory words: texture, warmth, grain, polish, depth, luminous
- Reference materials and process: earth, kiln, fire, craft, stone, clay
- Address the reader: "your space", "your vision", "you deserve"
- Avoid: "best", "amazing", "revolutionary", "world-class", "cutting-edge"

## Copy Templates

### Collection Description (short — for cards)
```
[Material origin/inspiration] meets [modern quality/aesthetic].
[Key visual characteristic] for [intended space type].
```
Example: "Italian Calacatta marble meets precision porcelain. Dramatic veining for statement surfaces."

### Collection Description (long — for detail pages)
```
[Opening hook about the visual/tactile experience]

[Material story — where it comes from, what inspired it]

[Technical excellence — size, thickness, finish, durability]

[Application suggestion — where it looks best]
```

### Space Description (for Find By Space cards)
```
[Adjective] tiles for [space type] that [emotional benefit].
```
Example: "Enduring tiles for kitchens that balance beauty and performance."

### Testimonial Format
```
"[Specific outcome/benefit]. [Quality/attribute praise]. [Emotional impact]."
— Name, Title, Company
   Project Name, Location
```

### CTA Copy
- Primary: "Request a Quote" / "Explore Collections" / "Visit Showroom"
- Secondary: "Download Catalogue" / "View All" / "Learn More"
- Text links: "Explore →" / "View Project →" / "Find a Store →"
- NEVER: "Click Here" / "Submit" / "Buy Now"

## Tile-Specific Terminology
Use correct industry terms:
- **Porcelain** (not "porcelain ceramic" — porcelain IS ceramic)
- **Glazed Vitrified Tiles (GVT)** — premium category
- **Large Format** — tiles 80x80cm and above
- **Rectified** — precision-cut edges for minimal grout lines
- **Body Color** — color throughout, not just surface
- **PEI Rating** — abrasion resistance (PEI 1-5)
- **Water Absorption** — <0.5% for porcelain
- **Slip Resistance** — R-rating (R9-R13)
- **Matt / Polished / Satin / Rustic / Carving** — finish types
