# Component Patterns

## Premium Button Pattern
- medium-large height
- clear contrast
- refined border or depth
- subtle hover lift
- elegant transition timing
- no childish rounding

## Premium Card Pattern
- layered background
- thin border
- soft shadow
- hover translateY small
- image-first where relevant
- strong padding system

## Image Showcase Pattern
- large visual dominance
- soft corner radius
- subtle overlay
- hover zoom
- controlled crop
- architectural framing

## Section Intro Pattern
- label / eyebrow
- strong statement headline
- concise premium supporting text
- balanced CTA placement
- spacing before content grid

## Trust / Stats Pattern
- fewer but stronger metrics
- elegant numeric scale
- clean separators
- avoid clutter
