# Prime Tiles Luxury Design System

## Color Direction
- Primary dark: #171717 / #1F1F1F / #222222
- Background light: #F7F3EE / #F4EFE8 / #F8F6F2
- Neutral support: #D9D0C7 / #B9B0A7 / #8D857D
- Accent metallic: subtle bronze / champagne / warm gold
- Optional support: muted olive / soft terracotta only when elegant

## Visual Mood
- Stone
- Marble
- Ceramic
- Polished surface
- Matte texture
- Architectural showroom
- Luxury editorial

## Typography Direction
- Large premium headlines
- Clean body copy
- Generous line-height
- Wide spacing around section titles
- Strong contrast between display and body text

## Surface Styling
- Thin borders
- Soft shadows
- Layered cards
- Matte / glass / stone-inspired backgrounds where appropriate
- Controlled gradients only if premium and subtle

## Section Rhythm
- Large vertical spacing
- Distinct section identities
- Alternating compositions
- Visual breathing room
- Product-first layout priority
